## 底部 4 个 Tab
首页 ｜ 探索 ｜ 收藏 ｜ 设置

---

## 页面跳转图

```
首页(Home)
 ├─ 点「自然」卡 → 自然首页
 ├─ 点「古诗」卡 → 古诗列表
 ├─ 点「认知」卡 → 认知首页(数字/拼音)
 ├─ 点「游戏」卡 → 游戏中心
 └─ 点「最近浏览」 → 自然详情 / 古诗详情

自然首页 → 点分类 → 自然卡片翻页 → 点卡片 → 自然详情
   自然详情 →「玩一玩」→ 拼图首页 / 找相同 / 配对游戏

古诗列表 → 点诗 → 古诗详情

认知首页 → 数字 / 声母 / 韵母 → 翻页卡片

游戏中心 → 拼图首页 / 选关卡 → 配对 / 找相同 / 分类 游戏

探索(Tab) → 随机发现卡 → 自然详情/古诗详情/数字/拼音/游戏
             「换一换」重抽

收藏(Tab) → 点收藏项 → 自然详情 / 古诗详情

设置(Tab) → 显示/年龄/语音包/家长门/更新日志
```

## 各页面功能

| 页面 | 怎么进去 | 有什么功能 |
|---|---|---|
| **首页 Home** | 底部 Tab | 4 张模块入口卡（自然/古诗/认知/游戏）；最近浏览快捷入口 |
| **自然首页** | 首页→自然卡 | 4 类（水果/蔬菜/动物/植物）分类卡 |
| **自然卡片翻页** | 自然首页→分类 | 左右翻卡片看图；收藏；普通话/粤语朗读 |
| **自然详情** | 翻页卡片 / 最近浏览 / 收藏 / 探索 | 大图；中粤语朗读；展开简介；「玩一玩」进拼图/找相同/配对 |
| **古诗列表** | 首页→古诗卡 | 按分类筛选；诗列表 |
| **古诗详情** | 古诗列表 / 最近浏览 / 收藏 / 探索 | 播放全诗/逐句朗读；拼音开关；注释；儿童白话译文 |
| **认知首页** | 首页→认知卡 | 3 类入口：数字 / 声母 / 韵母 |
| **数字翻页** | 认知首页→数字 | 0–9 翻页卡片 + 数量图示 + 朗读 |
| **拼音翻页** | 认知首页→声母/韵母 | 23 声母 + 24 韵母翻页卡片 + 例词 + 呼读音朗读 |
| **拼图首页** | 自然详情「玩一玩」/ 游戏中心 | 3 难度（4/9/16 块），逐级解锁，未解锁显示锁 |
| **拼图游戏** | 拼图首页→难度 | 拖动图块拼合；提示高亮；完成跳回自然详情 |
| **游戏中心** | 首页→游戏卡 | 4 种游戏入口 + 最近玩过 + 选关卡(1/2/3) |
| **找相同** | 游戏中心 / 自然详情 | 点出与示例相同的图；答错抖动提示，无惩罚 |
| **配对** | 游戏中心 / 自然详情 | 翻牌记忆配对 |
| **分类** | 游戏中心 | 把物品拖进正确分类桶 |
| **探索** | 底部 Tab | 随机推荐一个内容大卡；「换一换」重抽并朗读 |
| **收藏** | 底部 Tab | 已收藏的自然/古诗列表，点进详情 |
| **设置** | 底部 Tab | 字号/年龄模式；下载删除语音包；长按 3 秒家长门；更新日志 |

---

## 一句话导航总结
- **4 个内容模块**（自然/古诗/认知/游戏）从首页进入；游戏也可从自然详情「玩一玩」直达。
- **探索**是随机入口，可跳到任意内容详情或游戏。
- **收藏/设置**是独立 Tab。
- 详情页之间普遍可互跳（自然↔古诗、自然↔游戏）。
