## 3. 整体架构

### 3.1 入口与依赖注入

`GrowApp.swift` 以 `@main` 启动，`body` 中将全部单例注入 `@EnvironmentObject`，并用 `RootTabView` 承载四个底部 Tab（iOS 26 走原生 `TabView`，iOS 17/18 回退为 `ultraThinMaterial` 玻璃胶囊 tabBar）。首次启动触发 `VoicePackPromptModifier` 弹窗引导下载语音包。

### 3.2 底部 Tab 与导航

| Tab          | 根视图               | 说明                 |
| ------------ | ----------------- | ------------------ |
| 首页 Home      | `HomeView`        | 4 张模块入口卡 + 最近浏览    |
| 探索 Explore   | `ExploreRootView` | 随机「发现」大卡 + 换一换     |
| 收藏 Favorites | `FavoritesView`   | 收藏的自然/古诗           |
| 设置 Settings  | `SettingsView`    | 显示/年龄/语音包/家长门/更新日志 |

> 游戏中心（`GameHomeView`）通过首页「游戏」入口卡进入，不在底部 Tab 中。

各 Tab 内用 `NavigationStack` + path 实现深链（`ExploreTabRoot`/`NatureTabRoot`/`PoemTabRoot` 等），可深层 push 到详情/游戏页。

### 3.3 路由 Router

`Router.swift` 定义 `Tab`（home/explore/favorites/settings）、`NatureRoute`/`PoemRoute`/`ExploreRoute`，并解析 DEBUG 启动参数 `--tab=`、`--page=` 用于深链调试。

## 4. 界面功能清单

### 4.1 首页 `HomeView`

- 渐变背景（`Theme.homeBgTop/Bottom`）+ `BackgroundBlobs` 装饰。
- 4 张 `GlassEntryCard(module:)`：自然 / 古诗 / 认知 / 游戏（对应 `GrowModule`）。
- `RecentSection`：最近浏览的自然/古诗各最多 3 条（来自 `UserLibrary`）。
- 交互：点卡片进对应模块；点最近项进 `NatureDetailView` / `PoemDetailView`。

### 4.2 探索 `ExploreRootView`

- 随机「发现」大卡（图片 + 名称 + 一句话），「换一换」按钮重新抽取并朗读名称（`AudioManager.speak(key:"explore-...")`）。
- `makeDiscovery()` 从 自然/古诗/数字/拼音/游戏 中随机抽一条；点击进对应详情。

### 4.3 自然认知 `NatureViews` / `NatureDetailView`

- `NatureRootView`：4 张 `CategoryCard`（fruit/vegetable/animal/plant）。
- `NatureCardDeckView`：`TabView` 翻页卡片，进入即记录访问；`NatureCardFace` 含插画 + 收藏 + 中/粤语朗读按钮。
- `NatureDetailView`：大图插画；普通话/粤语朗读；可折叠简介（按 `settings.prefersLongDescription` 显示 short/long）；「玩一玩」区提供 3 个入口：`PuzzleHomeView`、`FindSameGameView`、`MatchingGameView`（游戏难度 `gameLevel = ageMode==.toddler ? 1 : 2`）。

### 4.4 古诗 `PoemListView` / `PoemDetailView`

- `PoemRootView`：顶部分类 chips（`PoemCategory`）筛选 + 列表卡片。
- `PoemDetailView`：插画 banner；播放全诗 / 按行朗读；拼音显隐开关；注释 `annotations`；儿童白话译文 `kidSummary`。

### 4.5 认知学习 `LearningViews`（数字 + 拼音）

- `LearningHomeView`：3 张分类卡（数字 / 声母 / 韵母）。
- `NumberView`：`TabView` 翻 `NumberCard`（数字 + 数量 emoji 网格）。
- `PinyinView`：`TabView` 翻 `PinyinCard`（字母 + 例词 + 呼读音朗读）。`PageDots` 页码点。

### 4.6 拼图 `PuzzleViews` / `PuzzleGameView`

- `PuzzleHomeView`：3 张难度卡（easy/medium/hard），按 `ProgressManager.isUnlocked` 显示锁定态；难度配色 easy=vegetable、medium=animal、hard=plant。
- `PuzzleGameView(item:)`：持有 `@StateObject PuzzleEngine`；`BoardFrameKey` 定位棋盘；运行时 `cropPiece` 裁剪 `UIImage`（不落盘）；拖拽图块到正确位置 + 提示高亮。完成写入 `GameResultStore`（type="puzzle"）。
- `PuzzleCompleteView`：经 `sourceNatureItemId` 链接回 `NatureDetailView`。

### 4.7 游戏中心 `GameHomeView` + 三大游戏

- `GameHomeView`：2×2 `gameCard` 展示 `games.playableDefinitions`（拼图/配对/找相同/分类）；`recentStrip` 来自 `GameResultStore.recentExplorations()`；`GameLevelPickerView`（level 1/2/3）。
- `FindSameGameView(level:focus:)`：持有 `FindSameEngine`，点选与焦点相同的图，错误用 `ShakeOnError` 抖动 + `GameFeedbackManager` 引导（无惩罚音效）。
- `MatchingGameView(level:focus:)`：持有 `MatchingEngine`，翻牌记忆配对；`prepareLevel` 强制插入焦点项。
- `SortingGameView(level:)`：持有 `SortingEngine`，拖物入两桶（L1=1 桶/L2=2/L3=3；松手 <60% 宽度视为未吸附）。
- 通用组件 `GameComponents.swift`：`GameIntroTip` / `GameOptionCard`（normal/correct/wrong）/ `GameShakeEffect` / `GameCompleteOverlay`（重玩/下一 + 链接自然详情）。

### 4.8 收藏 `FavoritesView`

- `library.favoriteNatureIDs` → `FavoriteNatureCell`；`favoritePoems` 列表；点击进对应详情。

### 4.9 设置 `SettingsView` / `DevLogView`

- 显示与年龄分区（`SizeLevel`/`AgeMode`、缩放因子）；`VoicePackCenterCard` 下载/删除语音包；`ParentGateCard` 长按 3 秒家长验证；链接 `DevLogView`。
- `DevLogView`：列出 `DevLog.all`（v0.4.2 → v0.1.0 完整更新日志）。

### 4.10 通用组件 `Components/`

- `Illustrations.swift`：`IllustrationView(identifier:)` —— `"img:"` 走 `AssetManager`（包内 HEIC/JPG/PNG）；`"emoji:"` 直接渲染；固定矢量 `Apple/Panda/Sunflower/NightRoom/GoosePond`；默认 `PlaceholderIllustration`。
- `SharedComponents.swift`：`WaveIndicator`（播放波形）、`LanguageButtonsRow`（普通话/粤语）、`FavoriteButton`（nature/poem）、`SpeakButton`（仅普通话，compact/prominent）。

## 5. 核心模块逻辑（Core）


### 5.1 资源与音频

- **`AssetManager`**：`bundleImage(_:)` 用 `NSCache`（countLimit 120）缓存；加载顺序 heic → jpg → png → asset catalog。被 `IllustrationView` 调用。
- **`AudioManager`**（单例，`SpeechLanguage`：mandarin=yue? 实为 mandarin=zh-CN、cantonese=yue-HK、english=en-US）：`speak(name:language:key:onFinished:promptIfMissing:)`、`speakPoem`、`speakPoemLine`、`stop`。路由策略：若 `useNaturalVoice` 且语音包就绪 → `NaturalTTSPlayer`（离线），否则系统 `AVSpeechSynthesizer`；粤语特殊处理。同一时刻自动 `stop` 防叠加。
- **`Voice/NaturalTTSPlayer`**：离线自然音 TTS，单例 `speak` 经 `SherpaOnnxOfflineTtsWrapper` 合成 WAV 后 `AVAudioPlayer` 播放；`isReady(for:)` 判断语音包就绪。
- **`Voice/VoicePack`**：语音包定义（`meloZhEn` 普通话·英语 ~53MB；`cantoneseXiaomaiiwn` 粤语 ~114MB；`all` 集合）。
- **`Voice/VoicePackManager`**：`State`（notInstalled/downloading/installed/failed）；`download`（Task + 2MB 分块 + `.part` 断点续传 + maxRetry 5）；`cancel`/`delete`；`VoicePackPromptCenter` 弹窗。
- **`Voice/SherpaOnnxWrapper`**：⚠️ vendored 的 k2-fsa sherpa-onnx Swift C-binding 封装（config 结构体、`toCPointer`、模型配置辅助），第三方依赖，未逐行审阅。
- **`SoundEffects`**：音效常量（`PuzzleSound` pick=1104/place=1057/complete=1025；`GameSound`）。
- **`JSONLoader`**：泛型 `load<T>(_ name:, as:)` 从 Bundle 解码 `Codable`，被各 Repository 复用。

### 5.2 内容仓库

- **`ContentRepository`**：`natureItems`/`poems`；`items(in:)`（按 `NatureCategory` 过滤）；`poem(id:)`。
- **`LearningRepository`**：`numbers`/`pinyins`；`pinyins(of:)`、`number(_:)`。
- **`PuzzleRepository`**：`puzzles`/`puzzles(in:)`/`puzzles(relatingTo:)`（按 `sourceNatureItemId` 关联自然条目）。

### 5.3 进度 / 收藏 / 设置

- **`ProgressManager`**：拼图进度（`"grow.puzzle.progress"` 字典）；`isUnlocked`（前一级完成才解锁）、`recordCompletion`。
- **`UserLibrary`**：收藏+最近浏览（`"grow.library."` 前缀）；`toggleNatureFavorite`、`recordNatureVisit`（最多 8）、`favoriteNatureIDs`/`favoritePoems`/`recentNatureIDs`/`recentPoemIDs`。`FavoriteManager = UserLibrary`（typealias）。
- **`SettingsManager`**：`SizeLevel`/`AgeMode`；缩放 `pageScaleFactor`/`fontScaleFactor`/`buttonScaleFactor`；`prefersLongDescription`；默认 `useNaturalVoice=false`、`puzzleAssist=toddler`。

### 5.4 游戏引擎（Core/Game）

- **`GameModels`**：`GameType`（puzzle/matching/findSame/sorting）、`GameDifficultyLevel`(1/2/3)、`GameDefinition`、`SortCategoryPair`、`GameLevelConfig`、`GameLevel`、`GameContentFile`、`GameSession`、`GameResult`。
- **`GameRepository`**：`definitions`/`levels`/`playableDefinitions`/`defaultLevel(of:)`（toddler→1 否则 2）/`natureItems(for:)`。
- **`GameResultStore`**：`"grow.game.results"`；`recentExplorations(limit:8)`；`record(gameId:level:completed:contentId:)`。
- **`GameFeedbackManager`**：无惩罚语音引导 `correct`/`retry`/`speakInstruction`（短语池），内部 `promptIfMissing:false`，**绝无错误音效**。
- **`GameEngine`**：`GameEngineProtocol` + `GameContentPicker`（`pick`/`distractors`/`including`/`shuffle`）。
- **`FindSameEngine`**：`Option`/`Round`/`prepare`/`choose`/`advance`/`reset`；`solvedTargets`。
- **`MatchingEngine`**：`Card`/`flip→FlipOutcome`(firstFlip/matched/mismatch/ignored)/`close`/`reset`；`pickedItems`。
- **`SortingEngine`**：`SortItem`/`Bucket`/`prepare`/`drop(into:)`/`reset`；`sortedItems`（用 `BucketFrameKey` 定位桶）。

### 5.5 拼图引擎 `PuzzleEngine`

纯逻辑：`PuzzlePiece`/`PuzzleState`；`createPuzzle`/`shufflePieces`/`isCorrectDrop`/`snapPiece`/`hintIndex`/`elapsed`。由 `PuzzleGameView` 以 `@StateObject` 持有，运行时裁剪 UIImage，不写盘。

## 6. 数据模型（Models）

- **`Content.swift`**：
  - `ContentKind` 内容种类枚举；`AgeLevel`（age23/age34/age45/age56）。
  - `ContentItem` 协议：`id`/`kind`/`displayTitle`/`illustrationID`/`storedAgeLevel`/`storedRelatedIDs`；默认 `age34`、`relatedIDs = []`。`NatureItem`/`Poem`/`NumberItem`/`PinyinItem` 均遵循此协议，`relatedContentIDs` 经 `storedRelatedIDs` 落地（用于「相关推荐/玩一玩」联动）。
- **`Models.swift`**：
  - `NatureCategory`：fruit/vegetable/animal/plant。
  - `NatureItem`：`id`/`category`/`nameZh`/`nameEn`/`descriptionShort`/`descriptionLong`/三语 `audio`（现均为 null）/`illustration`/`sortOrder`/`ageLevelRaw`/`relatedIDs`。
  - `PoemCategory`：14 个 case（night/family/nature/daily/spring…）。
  - `PoemLine`（text + pinyin）、`Annotation`（target + explanation）、`Poem`（title/author/dynasty/categories/illustration/lines/annotations/kidSummary/sortOrder）。
  - 文件包装 `NatureContentFile`/`PoemContentFile`。
- **`LearningModels.swift`**：
  - `NumberItem`、`PinyinType`(initial/final/tone)、`PinyinItem`(`symbol`/`exampleWord`/`exampleWordPinyin`/`image`/`speakText` 呼读音/`audio`；`speechContent` 拼接朗读)、`PuzzleDifficulty`(easy=2×2/medium=3×3/hard=4×4；`requiredPrevious`/`gameLevel`)、`PuzzleItem`(`image`/`difficulty`/`pieceCount`/`sourceNatureItemId`)。

## 8. 设计系统（`DesignSystem/`）

### 8.1 设计令牌

- **`Tokens.swift`**：`GrowSpacing`(xs4/s8/m16/l20/xl24)、`GrowRadius`(chip22/card28/sheet32/icon26)、`GrowAnimation`(press/appear/card/complete) —— **全部受 `animationOn` 与 `reduceMotion` 门控**。
- **`Theme.swift`**：颜色 `cream`/`ink`、四分类色 `fruit/vegetable/animal/plant`、`poemAccent/Warm/Paper`、`soft*`（softGreen/sand/blue/lilac）+ `deep*` 深色系、`homeBgTop/Bottom`、`heart`；`categoryColor(_:)`、`scaled(_:settings:)`（按设置缩放）、`GrowFont` 字号体系、`PressableButtonStyle`、`growCard` 修饰符。

### 8.2 Liquid Glass 实现（`GlassComponents.swift`）

- `GlassSurfaceStyle`/`glassSurface` 修饰符：
  - **iOS 26+**：`glassEffect(tint.map { Glass.regular.tint($0).interactive() } ?? Glass.regular.interactive(), in: shape)`（系统真·液态玻璃）。
  - **iOS 17/18 回退**：`.ultraThinMaterial` + tint 着色 + 顶部高光渐变 + 描边。
- 其余：`GlassCardStyle`/`glassCard`、`GlassButtonStyle`、`GlassPill`、`GlassButton`、`GlassIconBadge`、`GlassIconButton`、`GlassChip`、`GlassEntryCard`(vertical/horizontal)、`GlassPageHeader`。

### 8.3 图标与模块身份

- **`ModuleIdentity.swift`**：`GrowModule`(nature/poem/learning/puzzle)；`ModuleIconView`（Soft 3D squircle 图标）、`SoftIconContainer`；`NatureCategoryIcon`/`PuzzleDifficultyIcon`/`LearningTopicIcon`。
- **`GameIcons.swift`**：`GameModule`(puzzle/matching/findSame/sorting/locked，含 tint/deepTint，`from(_:GameType)` 映射)；矢量字形 `MatchingGlyph`/`FindSameGlyph`/`SortingGlyph`/`LockedGlyph`。

## 9. 已知限制与待办

1. **沙箱无 Xcode**：所有 Swift 代码未经真机编译，需在 Mac 上 ⌘B 验证。
2. **音频资源缺失**：全部内容 JSON `audio=null`，依赖 TTS/语音包合成；粤语/英语需先下载语音包（`VoicePackManager`）。
3. **`SherpaOnnxWrapper.swift`**（68.7KB）为第三方 vendored 封装，未逐行审阅。
4. **TTS 拼音呼读音**需在真机试听校验（如 eng→鞥、ong→嗡）。
5. **跨平台**：iOS 与安卓（`D:\AndroidDev\GrowAndroid`）是两套独立代码，功能对齐但非共享。
6. **关联联动**（`relatedContentIDs` / `sourceNatureItemId`）已贯通自然详情 → 拼图/游戏，新增内容时需在 JSON 中补齐关联字段。
